### 🚀 Featured Projects

#### ❤️ Health & Wellness Analytics Platform
*BigQuery · SQL · Python · GCP · Looker Studio · Cloud Run*

- Designed an end-to-end analytics solution that integrates **heart rate, HRV, sleep, activity, steps, and calorie data** for longitudinal health analysis.
- Developed SQL transformations and data-quality checks to identify **missing intervals, abnormal readings, sleep-stage patterns, and daily wellness trends**.
- Automated recurring ingestion and validation workflows using **Cloud Run, Cloud Storage, and BigQuery**, improving data availability and reporting reliability.
- Built decision-ready metrics for evaluating **sleep quality, recovery, activity behavior, and physiological trends**.

#### 🛒 Customer Segmentation & Revenue Analytics
*Python · SQL · Power BI · pandas · scikit-learn*

- Analyzed customer purchase behavior using **RFM analysis, cohort analysis, and clustering** to identify high-value, loyal, and at-risk customer segments.
- Created interactive dashboards to monitor **revenue, retention, average order value, customer lifetime value, and repeat-purchase behavior**.
- Translated segment-level findings into targeted recommendations for **customer retention, marketing prioritization, and revenue growth**.

#### 💰 Financial Performance & Forecasting Dashboard
*Excel · SQL · Power BI · Python*

- Developed a financial analysis dashboard comparing **actuals, budgets, forecasts, revenue, expenses, margins, and operating performance**.
- Automated variance calculations and drill-down reporting to identify key drivers behind changes in **profitability and cost performance**.
- Built forecasting views and scenario analysis to support management planning and resource-allocation decisions.

#### ⚙️ Operations & Process Performance Analytics
*SQL · Python · Tableau · Excel*

- Evaluated operational data to uncover **bottlenecks, cycle-time delays, SLA risks, capacity constraints, and recurring process failures**.
- Designed KPIs and dashboards for tracking **throughput, utilization, turnaround time, error rates, and service performance**.
- Applied root-cause and trend analysis to recommend improvements that strengthened operational efficiency and reporting transparency.
